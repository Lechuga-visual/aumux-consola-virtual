# AuMux application assets

The AuMux mark was supplied by the project owner in the conversation.
`aumux-logo-source.png` is the transparent application asset prepared from that
reference; `aumux-logo.png` is its 512px web representation. `aumux.ico` contains
16, 24, 32, 48, 64, 128 and 256px images for Windows shell resources.

The icon and web mark use the same design. Brand assets are bundled with the
application and source package.
